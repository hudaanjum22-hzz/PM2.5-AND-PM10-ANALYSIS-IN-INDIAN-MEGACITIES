# PM2.5-AND-PM10-ANALYSIS-IN-INDIAN-MEGACITIES
PM2.5 &amp; PM10 Air Quality Analysis in Indian Megacities is a Python-based Exploratory Data Analysis (EDA) project that examines air pollution levels across major Indian cities .Built using Python, Pandas, NumPy, Matplotlib, and Seaborn, this project demonstrates practical data analysis and visualization skills for environmental datasets.
